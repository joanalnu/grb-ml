## Requirements

You need to have a Python package manager (e.g., `pip`) in order to install this _Python package_. To use the package, you will also need to install the dependencies defined in `requirements.txt`.

## Installing from PyPI

The package is not yet available in to the public.

## Building from Source

You can clone the GitHub repository
```bash
git clone https://github.com/joanalnu/grb-ml.git
```

Then go into the directory and install the package
```bash
cd grb-ml
pip install .
```
