_This document outlines the policies for AI and/or LLM assisted software (and documentation) development within this project._

## Definitions

**contribution** any changes to the project's codebase in any of the branches, includes code development and documentation
**interaction** communication in person or via online means with a member and/or active contributor of the project about the project
**AI/LLM** software (website or applications, including CLI tools) using generative AI to produce or edit code and text. Common tools include those developed by OpenAI (ChatGPT), Anthropic (Claude), Google (Gemini), Microsoft (Copilot)

## Usage

One of the goals of the project (as part of the CAPIBARA Collaboration) is to train students and learners.

Since this is an educational project, we have decided for the following resolution:

AI/LLM systems may be used to guide the development and debugging of packages only under the application of 'learning' mode and never as a code generator.


## Failing to comply

Any suspicious of AI generated code will be investigated and we will determine the gravity of the issue.

The general rule is that we do not accept code or documentation writte by an AI/LLM.

Given the case, contributing AI generated code are ground to block any further contritbutions from that user.

## Exceptions

Code patches developed by Dependabot on GitHub in the context of the security features of GitHub may be accepted, obsviously upon review.

## Disclosure

Always share when you have used any kind of AI or LLM assistance or help when contributing to the repository (any branch) and when interacting with the community.
