## Overview

GRB-ML is a Python package that uses simulations and machine learning to rapidly predict whether a photon count signal is likely to be a Gamma-Ray Burst (GRB) or noise, cosmic rays, or other radiation like SAA. 

<CardGrid stagger>
	<Card title="Built for CubeSats" icon="rocket">
		Designed to run with limited resources, making it ideal for monitoring CubeSats (like EIRSAT) that must quickly decide whether to trigger a GCN event alert.
	</Card>
	<Card title="Lightweight & Efficient" icon="seti:python">
		Utilizes `sklearn`-based models to provide highly accurate yet efficient predictions suitable for personal computers or integration into other pipelines.
	</Card>
	<Card title="Easy Installation" icon="setting">
		Install locally with a simple command: `pip install -e .`.
